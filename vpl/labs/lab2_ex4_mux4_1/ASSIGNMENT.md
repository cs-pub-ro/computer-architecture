# Multiplexor 4:1
Implementați un multiplexor 4:1 (modulul `mux4_1`), cu intrările de date `i1`..`i4`, intrările de selecție `s1`, `s2` și ieșirea `out`. Tabelul de selecție (care intrare ajunge la ieșire pentru fiecare combinație `s2 s1`, și dacă ieșirea este negată) diferă de la student la student și se afișează în consolă la „Run”.

**Hint-uri**
- Consultați Laboratorul 0 pentru implementarea unui multiplexor 4:1.
- Respectați interfața cerută.
- Operatorul `?` poate apărea de mai multe ori într-o expresie. Ex: `assign x = (a == 0) ? 1 : ( (a == 1) ? 2 : 0 );`

Editați `mux4_1.v`. Valorile specifice fiecărui student se afișează în consolă la „Run” și „Evaluate”. Apăsați „Run” pentru a simula proiectul. Apăsați „Evaluate” pentru a fi notat.
